# fhir_r5_cds_hooks

[![pub package](https://img.shields.io/pub/v/fhir_r5_cds_hooks.svg)](https://pub.dev/packages/fhir_r5_cds_hooks)

CDS Hooks 2.0 client and service support for FHIR R5.

## Features

- CDS Hooks 2.0 model classes with JSON serialization
- Hook context classes for all standard hooks
- CDS client for discovery, invocation, and feedback
- Response builder and prefetch resolver for service implementations

## Getting Started

Add `fhir_r5_cds_hooks` to your `pubspec.yaml`:

```yaml
dependencies:
  fhir_r5_cds_hooks: ^0.5.0
```
